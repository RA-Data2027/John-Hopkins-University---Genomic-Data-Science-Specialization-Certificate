## 🐍 Course Overview
This repository / folder tracks my completion of **Python for Genomic Data Science** by Johns Hopkins University. The course focuses on introducing the Python programming language, the Jupyter/IPython notebook environment, and foundational programming concepts tailored toward parsing, manipulating, and analyzing biological sequence data.

---

## 📚 Syllabus & Core Modules Covered

### 1. Week 1: Overview of Python & Basics
* **Topics:** Introduction to Python syntax, basic operations, variables, and taking your first steps toward writing scripts.
* **Environment:** Setting up and navigating Jupyter/IPython notebooks for reproducible code execution.

### 2. Week 2: Data Structures, Ifs & Loops
* **Topics:** Working with core Python data structures (lists, dictionaries, tuples).
* **Control Flow:** Implementing conditional statements (`if`, `elif`, `else`) and iterative loops (`for`, `while`) to automate repetitive data tasks.

### 3. Week 3: Functions, Modules & Packages
* **Topics:** Writing modular, reusable code using custom functions, arguments, and scope.
* **Ecosystem:** Importing built-in and external modules/packages to extend Python's utility.

### 4. Week 4: Communicating with the Outside & Biopython
* **Topics:** Handling file input/output (File I/O) to read and write external files (such as text or sequence formats).
* **Bioinformatics Application:** Introduction to **Biopython** for specialized biological computations, handling sequence files (like FASTA/FASTQ), and basic pattern searching.

---

## 🛠️ Skills & Tools Acquired

* **Programming Fundamentals:** Writing clean Python scripts using proper syntax, data structures, and control flow.
* **Code Reusability & Modularity:** Structuring code with custom functions and utilizing third-party libraries.
* **File I/O:** Reading, parsing, and writing standard data and sequence files programmatically.
* **Bioinformatics Integration:** Utilizing **Biopython** and IPython/Jupyter notebooks for genomic data analysis tasks.
