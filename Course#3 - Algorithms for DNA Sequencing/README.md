**Institution:** Johns Hopkins University (via Coursera)  
**Specialization:** Genomic Data Science (Course in series)

---

## 🧬 Course Overview
This repository / folder tracks my completion of **Algorithms for DNA Sequencing** by Johns Hopkins University. The course covers the foundational computational methods, data structures, and algorithms used to process, index, align, and assemble massive genomic datasets, utilizing Python to implement solutions and analyze real biological sequences.

---

## 📚 Syllabus & Core Modules Covered

### 1. Week 1: DNA Sequencing, Strings and Matching
* **Topics:** Introduction to DNA sequencing technologies (past and present), representing genomes as strings and reads as substrings.
* **Concepts:** Basic string matching algorithms and implementation in Python.

### 2. Week 2: Preprocessing, Indexing and Approximate Matching
* **Topics:** Efficient algorithms for exact and approximate string matching.
* **Concepts:** Boyer-Moore algorithm, preprocessing text/patterns, index-based matching, and handling mismatches.

### 3. Week 3: Edit Distance, Assembly, Overlaps
* **Topics:** Solving the edit distance problem and related biosequence alignment challenges.
* **Concepts:** Global and local alignment, dynamic programming, and overlap-based genome assembly concepts.

### 4. Week 4: Algorithms for Assembly
* **Topics:** Advanced strategies for genome assembly.
* **Concepts:** Overlap graphs, De Bruijn graphs, Hamiltonian and Eulerian paths, and practical sequence reconstruction.

---

## 🛠️ Skills & Tools Acquired

* **String Algorithms & Bioinformatics:** Designing and implementing matching, alignment, and indexing algorithms (such as approximate searching and edit distance calculation).
* **Data Structures:** Working with specialized string structures and graph representations for genomic data.
* **Python Implementation:** Writing custom Python scripts to parse real genomic files (FASTA/FASTQ), manage quality scores, and solve algorithmic challenges.
