# Introduction to Genomic Technologies

This repository contains study notes, project workflows, and foundational implementations developed during the **Introduction to Genomic Technologies** course offered by **Johns Hopkins University** - Course 1/6 on Coursera.

## 📋 Course Overview

This course serves as an introduction to the basic biology of modern genomics, the experimental tools used to measure it, and the data science and computing structures required to analyze next-generation sequencing data. It bridges the gap between molecular biology and computational data analysis.

---

## 🗺️ Syllabus & Core Modules

### Module 1: Overview and Molecular Biology
*   **The Foundations:** Explored "just enough cell biology" to understand the genome and molecular biology structures.
*   **The Central Dogma:** Evaluated the pathway of genetic information flow from DNA transcription to RNA translation, mapping how genes express into physical phenotypes.
*   **DNA Architecture:** Examined physical DNA structure, sequences, and epigenetic modifications.

### Module 2: Measurement Technology
*   **Polymerase Chain Reaction (PCR):** Studied target DNA amplification and standard experimental benchmarking.
*   **Next-Generation Sequencing (NGS):** Analyzed how massive high-throughput sequencing frameworks break down and read raw genetic data.
*   **Sequencing Applications:** Evaluated the real-world applications of modern sequencing technologies in tracking genomic variations.

### Module 3: Computing Technology
*   **Algorithms & Data Structures:** Reviewed fundamental computer science concepts, memory allocation, and foundational data layout architectures.
*   **Efficiency:** Analyzed algorithmic runtime and space complexity metrics as they relate to high-volume biology pipelines.
*   **Computational Biology Software:** Introduced standard open-source tools and design frameworks used to navigate modern genomic software packages.

### Module 4: Data Science Technology & Course Project
*   **Statistics for Inference:** Explored the central dogma of statistical inference, study design, variability, and the critical importance of sample sizes.
*   **Batch Effects & Confounding:** Analyzed systematic experimental error sources, confounding variables, and power analysis.
*   **The Multiple Testing Problem:** Evaluated how checking thousands of genomic features shifts statistical significance thresholds, utilizing multi-testing adjustments.
*   **Course Project:** Designed and interpreted a data execution case study evaluating confounding variables and significance distributions over raw data arrays.

---

## 🛠️ Skills & Technologies Highlighted

*   **Domain Focus:** Bioinformatics, Molecular Biology, & Genetics.
*   **Computing Logic:** Data Structures, Algorithmic Efficiency, & Software Design Principles.
*   **Data Science:** Statistical Significance, Multiple Testing Corrections, Plotting, and Experimental Study Design.
